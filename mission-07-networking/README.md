

# Mission 7 — Computer Networking

Understand basic networking concepts and practise commands used to test network connectivity and communication.

## 2. Work Completed

## 3. Commands / Tools Used
- `ping` — tests connectivity and response time.
- `nslookup` — checks DNS resolution.
- `curl -I` — retrieves HTTP response headers.
- `ifconfig` — displays network interface information.
- `traceroute` — shows the route packets take towards a destination.

## 4. What I Understood
A computer network allows devices to communicate. DNS translates domain names into IP addresses. HTTP is used for communication between web clients and servers. Routers help forward network traffic between networks.

## 6. How I Solved Them
