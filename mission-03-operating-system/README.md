

# Mission 3 — Operating System

## 1. Task / Objective
Understand the operating system, running processes, storage, file paths and directory permissions.

## 2. Work Completed
- Checked the macOS version and operating system.
- Viewed running system processes.
- Checked available disk storage.
- Inspected directory permissions.
- Identified the current working directory.

## 3. Commands / Tools Used
- `sw_vers` — displays macOS version information.
- `uname -s` — displays the operating system kernel name.
- `ps -A` — lists running processes.
- `df -h .` — displays disk space information.
- `pwd` — displays the current directory.
- `ls -ld .` — displays directory permissions.

## 4. What I Understood
An operating system manages hardware, software, files and running processes. macOS uses the Darwin operating system foundation. File permissions control who can read, write or execute files and directories.

## 6. How I Solved Them
