## 3. Commands / Tools Used
- `pwd` — displays the current directory.
- `ls` — lists files and folders.
- `mkdir` — creates a directory.
- `touch` — creates an empty file.
- `cp` — copies a file.
- `mv` — moves or renames a file.

## 4. What I Understood
The terminal allows users to interact with the operating system using text commands. It is useful for navigating directories and managing files efficiently.
