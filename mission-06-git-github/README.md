

# Mission 6 — Git and GitHub

## 1. Task / Objective
Understand version control and practise using Git and GitHub to track and manage project changes.

## 2. Work Completed

- Viewed previous commits using `git log`.
- Checked existing branches.
- Created a new branch named `update-about`.
- Switched from the main branch to the new branch.

## 3. Commands / Tools Used
- `git status` — checks repository status.
- `git log --oneline` — displays commit history.
- `git branch` — lists branches.
- `git switch -c update-about` — creates and switches to a new branch.
- `git add` — stages changes.
- `git commit` — saves changes as a commit.
- `git push` — uploads commits to GitHub.

## 4. What I Understood
Git is a version control system that tracks changes in files. GitHub hosts Git repositories online and makes collaboration easier. Branches allow developers to work on changes separately from the main branch.
