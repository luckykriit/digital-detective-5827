

# Mission 5 — Number Systems and Data

## 1. Task / Objective
Understand decimal, binary and hexadecimal number systems and learn how computers represent text using character encoding.

## 2. Work Completed
- Converted decimal numbers into binary and hexadecimal.
- Converted binary and hexadecimal numbers into decimal.
- Created and tested a Python number converter.
- Explored ASCII and UTF-8 encoding.

## 3. Commands / Tools Used
- `bin()` — converts an integer into binary.
- `hex()` — converts an integer into hexadecimal.
- `int(value, base)` — converts a number from a specified base.
- `ord()` — returns the Unicode code point of a character.
- `encode('utf-8')` — encodes text into UTF-8 bytes.

## 4. What I Understood

Binary uses digits 0 and 1, decimal uses digits 0–9, and hexadecimal uses digits 0–9 and A–F.

ASCII represents a basic set of characters using numeric values. UTF-8 is a variable-length encoding that supports characters from many writing systems.
