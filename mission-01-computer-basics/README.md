# Mission 1 — Know Your Computer

## 1. Task / objective
Understand how a computer receives input, processes information, produces output and stores results. Identify hardware, software and computer-based systems.

## 2. Work completed

### Task 1.1 — Trace one activity using IPOS

**Chosen activity: Typing and saving a document on my MacBook.**

| Stage | What happens? | Hardware / component |
|---|---|---|
| Input | I type text using the keyboard. | Keyboard |
| Processing | The computer processes the typed characters and updates the document. | CPU and RAM |
| Output | The document and typed text appear on the screen. | Display |
| Storage | When I save the document, its data is stored for future access. | SSD |

**Explanation:**

When I type a document, the keyboard sends input to the computer. The processor and memory handle the information, and the display shows the result. When I save the document, it is stored on the SSD so I can open it later.
